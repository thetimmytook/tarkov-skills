# Privacy Policy

Tarkov Performance Benchmark and Tarkov Performance Toolkit process data locally on the user's Windows device.

The applications may read Escape from Tarkov graphics settings and logs, non-identifying Windows hardware and driver information, and FPS/frametime data produced by the bundled PresentMon utility. They do not read game process memory, automate gameplay, collect account credentials, or include user names, host names, local paths, IP addresses, serial numbers, or machine identifiers in generated reports.

No data is uploaded automatically. Copying, saving, or submitting a report requires an explicit user action. If a user chooses to submit data through an external form, that service's privacy terms also apply.

Local application data is stored in the Microsoft Store package's LocalState directory. Windows preserves it during application updates and removes it when the package is uninstalled, subject to Windows behavior and user backups.
