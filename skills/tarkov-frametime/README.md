# Tarkov Frametime

Read-only agent instructions for collecting or interpreting Escape from Tarkov FPS and frametime metrics.

## Use

The signed **Tarkov Performance Toolkit** includes the tested PresentMon dependency:

```text
tarkov-skills.exe status
tarkov-skills.exe capture --duration 120
```

In a web client, complete a run under **Benchmark**, press **Copy results**, and paste the latest-run JSON into the conversation. Existing PresentMon, CapFrameX, or FrameView CSV exports may also be interpreted manually.

This skill ships no executable scripts or capture utility. Automated capture requires Toolkit and explicit user consent.
